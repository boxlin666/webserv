
# Typescript Testing Setup
This project uses Vitest for integration testing to ensure our webserv robustness against HTTP protocol edge cases and concurrent connections.

1. Requirements
Node.js (v18 or higher recommended)

npm (usually comes with Node.js)

2. Quick Setup
If you are on the 42 iMacs or your own Linux environment, run this once to install the testing dependencies:

npm install
3. How to Run Tests
To compile the server and run the test suite:
npm test
